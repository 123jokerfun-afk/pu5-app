# ПУ-5 Дэр, дүнзний бүртгэл, хяналтын цахим систем

Төмөр замын дэр шалгалт бүртгэх PWA систем.

## Маягтын нэршил

- **ПУ маягт** (ПУ-5 гм) — Замын аж ахуйн тоо бүртгэлийн бичиг баримт
- **ПО маягт** (ПО-6 гм) — Тайлан тооцооны маягт

**Сайт:** https://123jokerfun-afk.github.io/pu5-app/
**APK:** [PU5.apk](PU5.apk) (Android дээр суулгах)

## Бүтэц
```
APK / PWA → GitHub Pages (index.html) → Firebase (Firestore + Auth)
                                             ↓
                                   Google Sheets (Apps Script)
```
