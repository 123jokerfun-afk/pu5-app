# ПУ-5 — шалгалт

Сервер урьдчилан асаах шаардлагагүй. Тест бүр өөрөө сул порт дээр
статик сервер асааж, repo-гийн `index.html`-ийг өгнө.

## Суулгах

```bash
cd tests && npm install     # зөвхөн exceljs — Excel-ийн шалгалтад
```

Playwright болон Chromium системд байвал өөрөө олно. Байхгүй бол:

```bash
npm i -D playwright && npx playwright install chromium
```

Chromium-ыг гараар зааж өгөх: `PU5_CHROME=/зам/chrome node allA.js`

## Ажиллуулах

```bash
node allA.js     # boot zero theme flow1 flow2 flow4 flow5 flow6 flow7
node allB.js     # flow8 flow9 overlap notch swhome
node allC.js     # үүлний бүтэц: sizeguard docid parts auto multi
node allD.js     # экспорт ба интерфэйс: ui2 raw tap swipe perf pack swrec admin pwa dbl edge exp xls sheet branch branchtr branch2 hub walk inv plan  (удаан)
node allE.js     # гүнзгий: deep live fuzz×5  (хамгийн удаан)
node sweepA.js   # 4 утасны байрлал
node sweepB.js   # үлдсэн 3 утас
node sweepC.js   # 7 утас ХЭВТЭЭ + 3 утас ГЭРЭЛТЭЙ загвар
```

Тусад нь: `node boot.js`, `node theme.js` гэх мэт.

## Дүрэм

Шалгалт нь **бодит алдаа** барих ёстой. Тест уначихвал эхлээд аппад
алдаа байгаа эсэхийг шалга — тестийг "засаж" өнгөрүүлэх нь хамгийн
муу зам. Хэрэв шалгалт өөрөө хуучирсан бол шалтгааныг тайлбартай
хамт өөрчил.

`stub.js` нь Firebase-ийг хуурамчаар орлуулдаг тул **жинхэнэ үүлтэй
холбоотой алдааг барихгүй**. Тийм өөрчлөлт хийвэл бодит нөхцөлд
тусад нь турш.

## Гүнзгий шалгалт (`allE.js`)

`fuzz.js` нь санамсаргүй үйлдлийн дараалал үүсгээд алхам бүрийн дараа
дараах **тогтмолуудыг** шалгана:

- `sec.repl`, `sec.plan`-ийн индекс бүр `[0, дэрийн тоо)` дотор
- сумын `dRepl`/`dPlan` нь дүнзний мужид, `slRepl`/`slPlan` нь рам замын мужид
- `sec.rw` нь ЗӨВХӨН бүртгэлийн дэлгэц дээр байна
- агуулахын тэнцэл: үлдэгдэл = орлого − зарлага (дэр ба дүнз хоёуланд)
- `_packDB` → `_unpackDB` дараа дэрийн тоо хэвээр
- бүх тоолуур (`collectPlan`, `derOutRows` …) алдаагүй ажиллана

Үр (seed) нь тогтмол тул **алдаа давтагдана**: `node fuzz.js 3 300`.
