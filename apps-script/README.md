# Google Sheets нэгтгэл

Админ дэлгэцээс сонгосон **он/улирлын** паспортоор хэсэг бүрд нэг шийт
үүсч, дотор нь 7 албан маягт дараалан, хооронд нь 4 хоосон мөртэйгээр
бичигдэнэ.

```
ПД-6 шийт
  Маягт-1              — гол зам, км тус бүр
  ····  (4 хоосон мөр)
  Маягт-1 Хавсралт-3   — өртөөний зам
  ····
  Маягт-1 Хавсралт-2   — 25%-аас дээш тэнцэхгүйтэй үе
  ····
  Маягт-1 Хавсралт-4   — сийрэгжилт
  ····
  Маягт-2              — сум бүрийн дүнзний нэгтгэл
  ····
  Маягт-2 Хавсралт-1.1 — Тэнцэхгүй / Сольсон
  ····
  Маягт-2 Хавсралт-1   — Байгаа / Тэнцэхгүй
```

## Яагаад тооцоо аппад хийгддэг вэ

Firestore дээр дэр бүр `'nnbn…'` гэсэн нэг тэмдэгт болж шахагдсан,
солигдсон дэрийн огноо нь өмнөх паспортад үлддэг (`resolveReplMap`).
Sheet-ийн томъёо эдгээрийг тайлж чадахгүй; тайлах код бичсэн ч аппын
тооцооны хоёр дахь хувилбар болж, ПУ-5 дээр өөр тоо гаргах эрсдэлтэй.

Тиймээс **маягтын мөрийг апп бүтээж, Apps Script нь зөвхөн хуулж
тавина**. `tests/sheet.js` нь Sheet рүү явах тоо бүрийг гарсан
Excel-ээс буцааж уншсан утгатай тулгаж шалгадаг.

Sheet дээр үлдэх ажил бол **харагдац**: нөхцөлт форматлалт, баганын
өргөн, шүүлтүүр, өөрийн нэмсэн pivot. Эдгээр нь аппын шинэ хувилбар
шаардахгүй.

## Суулгах

1. Хүснэгтээ нээгээд **Extensions → Apps Script**
2. `Code.gs`-ийн агуулгыг буулгана
3. Хүсвэл `TOKEN`-г нууц үгээр солино (хоосон бол шалгахгүй)
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. Гарсан `.../exec` холбоосыг аппын **Админ → Sheets** цонхонд буулгана
   (`TOKEN` тавьсан бол ард нь `?t=НУУЦҮГ` гэж залгана)
6. Мөн тэр цонхны **Маягт илгээх** товчийг дарна

## Анхаар

- Скрипт шийтийг **бүтнээр нь цэвэрлээд** дахин бичдэг. Гараар нэмсэн
  зүйлээ хэсгийн нэртэй шийтэд бүү үлдээ — тусдаа шийт дээр `=ПД-6!A1`
  байдлаар татаж ав.
- Хэрэглэгч бүрийн холбоос утсанд нь (`localStorage`) хадгалагдана —
  апп шинэчлэгдсэн ч устахгүй.
- Sheet бол **хуулбар**, эх биш. Тэндээс аппруу буцааж засвар орохгүй.
